# OShell terminal adapter

Derived from egoist/mygo plugins/terminal at bad73d119dc8d00a10daba45f19ba484e754d7a8, MIT license retained in LICENSE. Native libghostty-vt remains pinned by mygo-plugin.json.

OShell adds semantic input observation/replay, paste policy, copy trimming, output observation/logging, viewport search and highlight rendering. Upstream parser, PTY and renderer tests remain in this directory.
