# OShell 0.2.74～0.2.76 功能对齐

OShell Desktop 0.3.2 的构建目标为 Windows amd64 和 Linux amd64。

## 会话与窗口

- 头部提供会话管理、文件管理、会话侧栏、设置和更新入口。设置按钮打开独立设置窗口。
- 左侧树显示目录、实际会话和 `/Links` 引用；按名称、主机/IP、用户名、端口、目录搜索，保留祖先目录。清空搜索后恢复搜索前的展开状态。双击或 Enter 连接，配置修改后自动刷新。
- 默认 Ctrl+Shift+B 显隐侧栏，可在“设置 → 选择与侧栏”修改；快捷键冲突不会抢占已有功能。专注全屏临时隐藏侧栏。
- 会话管理已有 F2 / 右键重命名、行末完整属性编辑、Ctrl+C / Ctrl+V 多选复制。复制及身份变更继续使用现有密码解密、身份绑定与重新加密流程，已保存密码不回显。
- 终端标签支持组内排序、跨可见组移动和边缘滚动；文件窗口标签新增拖动排序、插入提示和边缘滚动，保留连接与内容。
- 文件窗口 Esc 最小化；Ctrl+W 关闭，活动传输继续走原有关闭确认。文件窗口与 SSH 窗口独立切换前后顺序。
- 文件连接可显式重新认证并重连，保留目录和记录。复制文件标签只复用活连接，不对失效连接偷偷重新认证。

## 本机工具提示符

`oshell>` 支持 Ctrl+A/E、Ctrl+B/F、方向键、Home/End、Backspace/Delete、Ctrl+U/K/W/Y/T/L、Alt+B/F / Ctrl+方向键、Tab 命令名补全、空行 Ctrl+D。

每个提示符独立保留最近 100 条非空命令；上下键 / Ctrl+P/N 浏览，Ctrl+R 反向搜索，Ctrl+S 向前搜索，Ctrl+G 恢复草稿及光标，Esc 取回匹配结果继续编辑，Enter 执行。有查询但无匹配时 Enter 不执行旧结果。编辑按 Unicode 字素处理中文、组合音标和 Emoji，长行水平滚动。

历史只记录本机提示符命令；工具运行后的 PTY 输入、SSH 密码或交互内容不进入历史。启动工具时会丢弃同一输入批次中命令之后的字节，避免把密码或远程输入带入下一个本机提示符。不解析完整 Shell 脚本、管道和重定向。

## 选词

“设置 → 选择与侧栏”集中提供自定义双击分隔符、重置、Shift+双击按空白选词、选中即复制及头尾空白清理。沿用原生终端选择引擎处理宽字符、软换行、三击选行和双击拖动扩选。

侧栏显隐、专用快捷键、选词分隔符和 Shift 方式写入本机 `desktop-preferences.json`，不进入共享合同。自动复制和空白清理沿用原有共享字段。

## 传输记录与 SFTP 续传

- 每个文件标签独立记录方向、开始时间、方式、实际目标路径、已传字节与结果；双击记录查看路径和错误。状态区分等待、传输中、成功、失败、取消、未执行和已暂停。
- 同一身份的文件标签重连时保留记录，更换身份或关闭标签后清除。最多保留 500 条已结束记录，未完成记录额外保留，列表按可见区域绘制。
- SFTP 普通文件支持暂停、继续、重试。继续 / 重试时如 SSH 已失效，会按原身份发起重连并继续；没有可用的保存凭据时仍须完成正常认证。
- 续传先校验源文件大小、修改时间及完整已传片段；本地源文件或片段替换也会被拒绝。临时文件名为 `.oshell-*.part`，完成后才发布最终文件，禁止覆盖现有目标。
- 上传续传需要服务器允许读取临时片段；远程发布使用 SFTP v3 无覆盖 RENAME，不使用有覆盖语义的 posix-rename。
- 目录、FTP、SCP 暂无续传，仍支持普通传输、记录及取消。暂停会结束本次批次，未开始项目需重新选择。
- 检查点和记录只存在当前进程内。关闭标签、退出应用或清除失败记录后不能恢复；未完成临时片段保留，可在确认不再需要后自行删除。
- 每个文件标签独立限速：SFTP / FTP 动态生效，SCP 下次传输生效。

## 兼容与验证边界

共享配置合同没有增加字段，继续读 v1/v2、写 v2，未知字段 / 版本拒绝应用和覆盖；会话归档继续支持 OShell.sessions 1～4。命令历史、传输记录和检查点不参与同步。

新增回归覆盖 Unicode 编辑、历史搜索无匹配、工具输入隔离、侧栏过滤和本地配置、宽字符 / 软换行选词、SFTP 暂停续传、断线重连、源文件变更、片段损坏及目标覆盖保护。CI 在容器中编译两平台程序和测试；Windows 原生执行完整预编译测试，Linux 在容器虚拟显示中执行桌面回归。人工交互体验仍需分别在两平台验收。

用户提供的真实 Swift ↔ Go 互通结果对应提交 `28571b3`。本次没有改动共享协议，Windows 上的 Go 兼容样本不等同于重新完成真实 Swift 双端验证，发布前仍按 AGENTS.md 在 macOS 执行互通脚本。

Touch ID、Secure Enclave、Space、钥匙串及 Apple 签名不移植到 Windows / Linux。本次不构建 macOS 版本。
