# macOS OShell 与 OShell Desktop 共用配置

开发者字段及线格式约定见 [共享配置协议 v2](configuration-protocol-v2.md)。本文只说明接入与使用。

两个应用通过共享加密文件双向同步，各自保留独立的本机工作副本。不要把两个应用的本机数据目录设置成同一个目录，也不要直接用云盘同步整个程序数据目录。

## 接入已有 macOS OShell 数据

1. 先升级全部参与节点到支持统一 v2 协议的版本；旧客户端会拒绝 v2 文件，不能继续编辑共享配置。然后在所有节点设置并解锁**相同的主密码**。WebDAV 登录密码与这个主密码是两个不同用途的密码。
2. 在已有数据的 macOS OShell 中启用 WebDAV 或同步目录，先完成一次同步。原版共享要求保存的密码使用主密码保护；如有本机自动加密密码，先在原版转换为主密码保护。
3. OShell Desktop 的“设置 → 存储 / 配置同步”选择相同同步方式和目标。WebDAV 填写同一个 HTTPS **目录地址**及账号，不要填写文件 URL；目录同步选择本机挂载或同步到的共享目录路径。
4. 第一次同步已有数据时选择使用共享数据；需要带入本机已有会话时选择合并，并确认出现的差异。首次替换会备份本机配置。
5. 之后各节点继续使用同一目标。无需手动导出再导入。离线使用本机副本，恢复连接并解锁后再同步。

每个节点的同步地址、登录凭据和同步基准保存在本机，首次接入每台设备需要配置一次。配置里的私钥**路径**可以同步，私钥文件不会上传；跨系统路径须在对应节点可用。字体、系统快捷键及平台专属功能仍取决于当前设备。

## 共享协议

| 项目 | 统一约定 |
| --- | --- |
| WebDAV 对象 | 目录下的 `oshell-vault.json` |
| 同步目录对象 | 目录下的 `configuration.json` |
| 外层格式 | `OShell.shared-vault`，写入版本 `2`，兼容读取 `1` |
| 密钥派生 | PBKDF2-HMAC-SHA256，16 字节盐，写入 600000 轮，32 字节密钥 |
| 加密 | AES-256-GCM；`ciphertext` 为 12 字节 nonce + 密文 + 16 字节 tag，Base64 编码 |
| 附加认证数据 | v2 使用 UTF-8 `OShell.shared-vault.v2`；读取 v1 使用原 AAD |
| 内容 | 原版 `Configuration`：会话、共享代理、目录、快捷引用、快速命令、突出显示、默认会话属性、偏好及主密码校验器 |
| 保存的密码 | 原版 `EncryptedPassword` 协议，按会话身份绑定；共享文件不含本机密钥引用 |
| 快速发送范围 | JSON 整数：0 当前、1 标签、2 全部、3 可见、4 所选、5 当前组、6 所选组 |

Desktop 兼容读取旧版写出的字符串快速发送范围，在条件写入保护下升级为原版整数。空列表、代理默认认证方式和深色配色标记也采用原版的稳定编码，避免无修改反复上传。编码升级不作为用户配置冲突；对端数据发生变化仍拒绝覆盖。所有参与同步的 Desktop 节点都应升级，避免旧版重新写入不兼容格式。

本地 `config.json`、`credentials.json` 和原版本地存储实现无需相同；共享层保证交换文件一致。不要上传 `credential-key`、`local-credential-key.json`、日志、主机指纹、本机同步基准或签名私钥。

## 多节点一致性

WebDAV 必须提供强 ETag，并正确支持 `If-Match` / `If-None-Match`。不同会话的独立修改可合并，同一会话同时修改需要选择；未解决的冲突不会覆盖远端。共享代理及其他配置区块按区块处理冲突。远端被删除、密码错误、数据损坏或版本变化时停止覆盖，保留本机数据。

同步目录交换相同加密内容，使用版本摘要及本机文件协调。跨设备云盘的异步复制不等同于服务端原子提交；出现云盘冲突副本须先保留并处理。需要多节点同时编辑时，使用支持条件写入的 WebDAV。共享副本最终一致，不是所有窗口实时共用一个正在写入的数据库。

## 验证

普通 Go 测试在 macOS / Windows 上读取真实 Swift 核心生成的合成测试文件，并检查密码、代理引用和字段兼容：

```sh
go test ./internal/core -run 'Test(NativeSwiftSharedFixture|SharedQuickSendScope|LegacySharedProtocol)'
```

macOS 上使用原版源码执行真实双向及多节点测试：

```sh
python3 scripts/test-sync-interop.py --native-source /path/to/OShell
```

脚本只读原版核心源码，编译到临时目录，以模拟 WebDAV 和独立临时目录检查 Swift → Go → Swift、密码解密、不同会话合并、同会话冲突、过期写入拒绝以及无变化不重复上传。不会连接用户服务器或读取真实配置。
