# 与 macOS OShell 同步配置

两端通过共享加密文件交换配置，各自保留本机数据。不要共用本机数据目录，也不要用云盘同步整个程序目录。

## 首次接入

1. 将所有设备升级到支持共享协议 v2 的版本，并设置、解锁相同主密码。WebDAV 登录密码与主密码用途不同。
2. 在已有数据的 OShell 上启用 WebDAV 或同步目录，先完成一次同步。保存的密码须使用主密码保护；本机密钥保护的密码先转换。
3. 在 Desktop 的“设置 → 存储 / 配置同步”选择同一目标。WebDAV 填 HTTPS **目录地址**，不要填文件 URL；目录同步选择对应的共享目录。
4. 首次接入选择使用共享数据，或合并本机会话并确认差异。首次替换会备份本机配置。
5. 每台设备分别保存同步地址和登录凭据；离线时使用本机副本，联网并解锁后再同步。

## 同步范围

会话、目录、代理、保存密码、快捷引用、快速命令、突出显示、默认会话属性和共享偏好参与同步。私钥只同步路径，不上传文件；字体、路径和快捷键仍需适用于本机。

本机密钥、WebDAV 凭据、主机指纹、日志、同步基准、侧栏和选词设置、命令历史、传输记录、续传检查点不参与同步。

| 目标 | 加密文件 |
| --- | --- |
| WebDAV | 目录下的 `oshell-vault.json` |
| 共享目录 | `configuration.json` |

两端读取共享版本 1 / 2，写入版本 2。未知版本或字段会拒绝应用和覆盖，请先升级全部设备。会话归档 `OShell.sessions` 的 1–4 版本与共享版本无关。

## 冲突与故障

- 不同会话的修改可合并；同一会话并发修改需要确认，未解决前不覆盖远端。
- WebDAV 必须支持强 ETag 和条件写入。目标删除、密码错误、损坏或版本不支持时，保留本机数据并停止覆盖。
- 共享目录和云盘不保证跨设备原子写入。多设备同时编辑建议使用合规 WebDAV；出现云盘冲突副本时先保留并处理。

字段、加密和验收规则见 [共享配置协议 v2](configuration-protocol-v2.md)。
